🧠 Quick Learning

📍 Reference point
Used to describe the position or motion of another object.
🧍 Rest
Position does not change relative to the reference point.
🚗 Motion
Position changes relative to the reference point.
➡️ Straight-line
Motion along a straight path.
⭕ Circular
Motion along a circular path.
⚙️ Rotational
An object spins around its own axis.
🔁 Periodic
Motion that repeats at regular intervals.
